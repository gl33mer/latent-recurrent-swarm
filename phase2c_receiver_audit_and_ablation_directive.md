## 1. Executive Mission & Context

The 15-run confirmatory experiment on Phase 2c confirmed a decisive negative result: Core B was unable to learn message-conditioned reachability under the tested recipe (overall accuracy ~60.5%, forced relation accuracy 58–70%, switch consistency 2–17%).

Before spending compute on further 15-seed sweeps or redesigning the communication channel, we must establish **why Core B failed**. 

We have two primary hypotheses:
1. **The Task/Distribution Mismatch Hypothesis:** The Phase 1 reasoner cannot solve the new graph distribution even when given a single relation directly.
2. **The Union-Mask Interference Hypothesis:** The reasoner can easily solve single-relation reachability, but masking on $R_0 \cup R_1$ while encoding relations solely in 64-dim node features destroys the topological inductive bias needed for pathfinding.

This directive executes a **2-stage, zero-bloat diagnostic** (< 5 minutes total CPU wall-time) to definitively resolve this question.

## 3. Stage 0: Frozen Phase 1 Baseline Transfer Check (Zero Training)

**Objective:** Test whether the existing, known-good Phase 1 checkpoint (`checkpoint_phase1.pt`) transfers directly to the individual relation graphs generated by the Phase 2c benchmark.

### Implementation Specification (`audit_stage0_transfer.py`):
1. Load `checkpoint_phase1.pt` into a standard `LatentReasoner(num_nodes=16, d_input=32, d_model=128)`.
2. Generate 1,000 validation samples using the Phase 2c data generator (`generate_parity_benchmark` or `generate_conditioned_benchmark`).
3. For each sample, construct:
   - **Evaluation Set $R_0$:** Node features = $[A_0,\, \text{onehot}]$ (shape `[16, 32]`), Attention Mask = derived strictly from $A_0$. Target = reachability in $R_0$.
   - **Evaluation Set $R_1$:** Node features = $[A_1,\, \text{onehot}]$ (shape `[16, 32]`), Attention Mask = derived strictly from $A_1$. Target = reachability in $R_1$.
4. Evaluate at recurrent depth $T=8$.
5. **Decision Logic:**
   - If Accuracy on both $R_0$ and $R_1$ is $\ge 90.0\%$: The underlying reasoner transfers cleanly to the new graphs. The failure is isolated to the combined multi-relation task/representation. Proceed immediately to Stage 1.
   - If Accuracy is $< 80.0\%$: The Phase 2c graph distribution itself broke the base reasoner. Stop and report graph distribution divergence.

## 4. Stage 1: Matched Single-Relation Mask Ablation (3-Minute CPU Training)

**Objective:** Isolate the causal effect of the union attention mask ($R_0 \cup R_1$) versus the native relation mask ($R_0$) while holding all input features, targets, models, and hyperparameters 100% identical.

### Experimental Design:
We train two models on **identical input data and targets**:
* **Target:** Reachability in Relation 0 ($b_{A0} \in \{0, 1\}$).
* **Input Features:** The full 64-dimensional Phase 2c feature vector:
  $$x_i = [A_{\text{union}}[i],\, A_0[i],\, A_1[i],\, \text{onehot}(i)] \in \mathbb{R}^{64}$$
* **Architecture:** `LatentReasoner(num_nodes=16, d_input=64, d_model=128)`
* **Training Budget:** 20 epochs, AdamW (`lr=1e-3`, `weight_decay=1e-2`), batch size 64, fixed recurrent depth $T=8$.

### The Only Variable:
* **Condition A (Native Mask):** Attention mask is constructed strictly from $A_0$ (ignoring $A_1$ edges).
* **Condition B (Union Mask):** Attention mask is constructed from $A_{\text{union}} = A_0 \lor A_1$ (the Phase 2c setup).

### Implementation Details (`audit_stage1_ablation.py`):
- Ensure `LatentReasoner` supports an explicit `attn_mask` override in its `forward()` call so that input features remain 64-dimensional while the mask is manipulated independently.
- Train Condition A for 20 epochs; record training curve and final validation accuracy.
- Train Condition B for 20 epochs; record training curve and final validation accuracy.

### Causal Decision Matrix:
| Condition A ($A_0$ Mask) | Condition B ($A_{\text{union}}$ Mask) | Scientific Conclusion | Next Move |
| :---: | :---: | :--- | :--- |
| **$\ge 90\%$** | **$\le 70\%$** | **Union mask interference confirmed.** Standard dot-product attention cannot filter out $R_1$ edges from node features alone. | Close Phase 2c; do not train union masks. |
| **$\ge 90\%$** | **$\ge 90\%$** | **Mask interference rejected.** The model CAN filter relations; the Phase 2c failure is strictly due to the COMM token dynamics or XOR head. | Investigate COMM token routing. |
| **$< 75\%$** | **$< 75\%$** | **Feature representation failure.** Packing multiple adjacencies into 64-dim node features destabilizes the encoder. | Redesign input encoding. |
